# Путешествуй!

Веб-планировщик путешествий с интеграцией DeepSeek API. Заполняете параметры поездки — получаете подробный план по дням: активности, гастрономия, практические советы и бюджет-ориентиры.

## Возможности

- Параметры поездки: город, даты, количество взрослых и детей
- Генерация плана через `deepseek-chat` по вашему API-ключу
- Экспорт плана: печать и сохранение в PDF (A4, 3 страницы)
- Готовый пример плана в интерфейсе — можно посмотреть без ключа
- Рендеринг ответа: заголовки, `**жирный**`, `*курсив*`, списки без маркеров
- `Ctrl+Enter` / `Cmd+Enter` — быстрый запуск генерации

## Запуск

Проект статический, сборка не нужна. Достаточно открыть `index.html` в браузере, но лучше поднять локальный сервер, чтобы внешние `styles.css` и `script.js` гарантированно подхватились:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Структура

```
index.html                разметка планировщика
styles.css                стили
script.js                 логика: запрос к DeepSeek, рендеринг ответа, валидация, печать
plans/
  index.html              галерея готовых планов
  kazan-2026-01-03.html   готовый план: Казань, 3–8 января
docs/                     локально, в репозиторий не выкладывается
  ROADMAP.md              план развития, юзер-стори
  CHANGELOG.md            лог изменений
  tasks/                  задачи с описанием и промптами
```

## API-ключ

Ключ вводится в поле «DeepSeek API-ключ» прямо в браузере. Он **не сохраняется** и отправляется только на `api.deepseek.com`.

## Скриншот / пример

Пример готового плана (Москва, 3–8 января, 8 взрослых + 5 детей) уже вшит в `index.html` — он виден сразу при открытии страницы.

## Требования

- Браузер с поддержкой `fetch` и ES2015+
- Аккаунт DeepSeek с API-ключом (для генерации собственного плана)
